IA LOCAL - JAVVA para Eclipse

O Javva dentro do Eclipse: sessões, conversa, fotos e comandos no seu computador com "Permitir?".

  1. Baixe o javva-eclipse-site.zip (não precisa descompactar).
  2. No Eclipse: Help → Install New Software… → Add… → Archive… → escolha o zip → Name: IA LOCAL - JAVVA → Add.
  3. Marque IA LOCAL → Next → Next → Finish.
  4. Se aparecer Trust (conteúdo sem assinatura): marque e clique Trust Selected / Install Anyway.
  5. Reinicie o Eclipse. Abra pelo menu IA LOCAL → Abrir o Javva (ou o botão azul "J" da barra).
Por que não colar este endereço em Location? O Eclipse novo troca http:// por https:// sozinho e a instalação falha. Para usar o endereço direto (e receber versões novas em Help → Check for Updates), acrescente no fim do eclipse.ini, depois de -vmargs, a linha -Dp2.httpRule=allow, reinicie o Eclipse e use Location http://192.168.68.106:8787/eclipse/.

Servidor diferente? Window → Preferences → IA LOCAL - JAVVA.
